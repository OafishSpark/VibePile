# event-viewer

Виджет на Tkinter + matplotlib для просмотра и ручной разметки последовательностей событий.

Каждое событие — строка `pandas.DataFrame` с уникальным индексом, моментом времени и признаками.
Виджет показывает:

- графики «признак(время)» друг под другом с общей осью времени (зум, панорамирование и
  остальные инструменты стандартного toolbar matplotlib);
- прокручиваемую таблицу событий; выделенные события в ней подсвечиваются;
- кнопки «Снять выделение», «Сохранить CSV» и «Далее» (для разметки нескольких наборов подряд).

Рассчитан на наборы примерно до 1000 событий.

## Установка

Нужны Python ≥ 3.9, numpy, pandas, matplotlib ≥ 3.6 и Tkinter (входит в стандартную поставку
Python; в Linux иногда ставится отдельно, например `apt install python3-tk`).

```bash
pip install -e .            # из папки с pyproject.toml
pip install -e .[test]      # вместе с pytest
```

Без установки можно просто положить папку `event_viewer` рядом со своим скриптом.

Демо: `python -m event_viewer`

## Быстрый старт

```python
import tkinter as tk
from event_viewer import EventViewer, Segments

root = tk.Tk()
viewer = EventViewer(
    root,
    time_col="time",
    panels=[
        "p0",                                                # точки
        "p1",
        Segments(start="p2", end="p2_end", duration="dur"),  # отрезки с точкой в центре
    ],
    table_cols=None,         # None — все колонки DataFrame
    font=("Arial", 10),      # шрифт таблицы и кнопок; None — системный
)
viewer.pack(fill=tk.BOTH, expand=True)
viewer.load(df, selected=[5, 10])   # selected — метки df.index, выделенные изначально
root.mainloop()
```

## Последовательная разметка нескольких наборов

`wait_next()` ждёт нажатия «Далее», не блокируя окно, и возвращает метки выделенных событий.
Если окно закрыли, возвращает `None`. `mainloop()` в этом режиме не нужен.

```python
results = {}
for name, df in datasets.items():
    viewer.load(df, selected=previous_marks.get(name))
    marked = viewer.wait_next()
    if marked is None:      # окно закрыли
        break
    results[name] = marked
else:
    root.destroy()
```

## Управление мышью

| Действие | Результат |
|---|---|
| Клик по точке или отрезку | Переключить выделение события |
| Протянуть окно на графике | Добавить в выделение события, которые окно задело хотя бы частично |
| Клик по строке таблицы | Переключить выделение события |
| Зум / панорамирование в toolbar | Пока режим включён, выделение мышью отключено |

После выделения окном таблица прокручивается к первому выделенному событию.
Если отрезки перекрываются, клик выбирает ближайший к курсору.
Границу между графиками и таблицей можно перетаскивать мышью.

## Панели

**`Points(y, name=None, size=14)`** — значение колонки `y` в момент события.
Строка в `panels` — сокращение для `Points(строка)`.

**`Segments(start, end, duration, unit="s", name=None, linewidth=1.5, size=14, center=True)`** —
отрезок от `(t, start)` до `(t + duration, end)` и точка в его центре (`center=False` — без точки).

Единицы длительности:

| Время | Длительность | Как трактуется |
|---|---|---|
| даты | `timedelta` | точно |
| даты | число | в единицах `unit`: `"s"`, `"ms"`, `"min"`, … |
| числа | число | в тех же единицах, что время |
| числа | `timedelta` | в секундах |

### Своя панель

Достаточно класса с тем же интерфейсом, что у протокола `Panel` (менять остальной код не нужно):

```python
class MyPanel:
    label = "Подпись оси Y"

    def geometry(self, df, t, time_is_datetime):
        """float64-массив (n, 2, 2): начало и конец каждого события в координатах данных.
        Точка — отрезок нулевой длины. По этой геометрии работают клик и выделение окном."""

    def draw(self, ax, geom, color):
        """Нарисовать события и вернуть список артистов. У каждого artist.set_color(colors)
        с colors формы (n, 4) должен красить события в порядке строк."""
```

## Таблица и форматирование

- Индекс показывается всегда, первой колонкой.
- Дробные числа округляются до тысячных, целые выводятся как есть, даты — с миллисекундами,
  длительности — в секундах.
- Ширина колонок считается по самому длинному значению жирным шрифтом, поэтому текст не наезжает.

## API `EventViewer`

| Метод / свойство | Описание |
|---|---|
| `load(df, selected=None)` | Показать новый DataFrame (сортируется по времени), выделение сбрасывается |
| `select(labels)` | Добавить в выделение события по меткам индекса |
| `toggle(row)` | Переключить событие по позиции строки в `viewer.df` |
| `clear_selection()` | Снять всё выделение |
| `selected` | Копия bool-маски выделения по строкам `viewer.df` |
| `selected_index` | Метки выделенных событий |
| `selected_df` | Выделенные строки |
| `save_selected(path=None)` | Сохранить выделенные строки в CSV; без `path` откроется диалог |
| `wait_next()` | Ждать «Далее»; метки выделенных или `None`, если окно закрыли |
| `plot`, `table` | Вложенные `EventPlot` и `EventTable` |

## Шрифты

- Таблица и кнопки — параметр `font` (`("Arial", 11)`, имя шрифта Tk или `None`).
- Подписи на графиках задаёт matplotlib, до создания виджета:

  ```python
  import matplotlib
  matplotlib.rcParams["font.family"] = "Arial"
  matplotlib.rcParams["font.size"] = 9
  ```

## Устройство пакета

```
event_viewer/
├── conversion.py  # столбцы -> float64 и -> строки таблицы, единицы длительности
├── geometry.py    # расстояние до отрезка, пересечение отрезка с прямоугольником (numpy)
├── panels.py      # протокол Panel и панели Points, Segments
├── table.py       # EventTable: Treeview с прокруткой и подсветкой
├── plot.py        # EventPlot: графики, toolbar, обработка мыши
├── viewer.py      # EventViewer: связывает графики и таблицу, хранит выделение
└── demo.py        # синтетические данные и пример последовательной разметки
```

Зависимости направлены в одну сторону: `viewer` → `plot`, `table` → `panels` → `conversion`,
`geometry`. `EventPlot` и `EventTable` выделение не хранят: они сообщают о действиях
пользователя через колбэки и показывают то, что им передал `EventViewer`. Поэтому их можно
использовать по отдельности.

## Ограничения

- Отрисовка нового набора занимает доли секунды, в основном на отрисовку matplotlib.
- В некоторых сборках Tk на Windows фон строк таблицы через теги не отображается;
  жирный шрифт выделенных строк работает всегда.
- Отрезки очень короткие относительно диапазона времени видны как вертикальные чёрточки;
  чтобы их рассмотреть, приблизьте участок по оси времени.
